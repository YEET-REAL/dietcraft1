EASY BUILD (no installs):
1. Make a free account at github.com
2. Click + (top right) > New repository. Name it dietcraft. Create it.
3. Click "uploading an existing file". Drag in EVERYTHING from this folder
   (including the hidden .github folder), then Commit.
4. Click the "Actions" tab. Wait ~3-5 minutes for the green check.
5. Click the finished run > scroll down to Artifacts > download DietCraft-jar.
6. Unzip it: that's dietcraft-1.0.0.jar. Put it in your mods folder with Fabric API.
